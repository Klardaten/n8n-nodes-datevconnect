# Klardaten DATEVconnect Identity & Access Management

This community node provides access to DATEVconnect Identity & Access Management through the [Klardaten DATEVconnect Gateway](https://klardaten.com/products/datevconnect-gateway).

On a self-hosted n8n instance, install the package through **Settings → Community Nodes → Install** using `@klardaten/n8n-nodes-datevconnect-identity-and-access-management`. Add the node to a workflow and select a **DATEVconnect API** credential.

See the [repository README](https://github.com/Klardaten/n8n-nodes-datevconnect#readme) for credential setup and workflow migration.
